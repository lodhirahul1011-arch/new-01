# Mobile Delivery Enhancements

Added and rechecked for the mobile delivery screens:

- delivery dashboard endpoint with summary cards and mobile-friendly item payloads
- richer delivery detail payload for date, time, verification code, rating, verification methods, rejection screen content
- rejection reasons catalogue with code + label + description

- monthly report upgraded with previous month comparison, category percentages, family member breakdown, export links, WhatsApp deep link, and security insights
- new automated test script: `npm run test:mobile-delivery`
- Postman folder and standalone collection for mobile delivery testing
